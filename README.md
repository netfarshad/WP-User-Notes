# WP-User-Notes
افزونه وردپرس برای یادداشت خصوصی بین کاربران و لیست وظایف شخصی.
افزونه وردپرس برای ارسال یادداشت خصوصی بین کاربران و مدیریت لیست وظایف شخصی در داشبورد.
## امکانات
- ارسال یادداشت خصوصی بین کاربران
- صندوق ورودی و ارسال‌شده‌ها
- وضعیت خوانده‌شدن پیام
- لیست وظایف شخصی (To-Do) با رنگ‌بندی
- آرشیو پیام‌ها با صفحه‌بندی
- امنیت: Rate Limiting، Nonce، Prepared Statements
## نصب
1. فایل zip را دانلود کنید
2. در وردپرس: افزونه‌ها ← افزودن ← بارگذاری
3. فعال‌سازی

# WP User Notes

A WordPress plugin for sending private notes between users and managing a personal task list within the dashboard.

## Features
- Send private notes between users
- Inbox and Sent items
- Read/Unread message status
- Personal To-Do list with color coding
- Message archiving with pagination
- Security: Rate Limiting, Nonces, Prepared Statements

## Installation
1. Download the ZIP file
2. In WordPress: Plugins → Add New → Upload Plugin
3. Activate the plugin
